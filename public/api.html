واجهة مون البرمجية

كل كتاب منشور في فهرس مون، وكل شخص وموضوع ومحور، بيانات BIBFRAME مترابطة لها عنوان دائم على mooon.site. هذه الصفحة تشرح كيف تقرؤها المكتبات والباحثون والبرامج. لا تحتاج إلى مفتاح أو تسجيل دخول: كل ما هنا عام، وتُعرض فيه النسخ المنشورة وحدها.

العناوين الدائمة (Resolvable URIs)

لكل كيان عنوان لا يتغير. يفتحه المتصفح على صفحة الكتاب في الفهرس، وتأخذ منه البرامج البيانات بالصيغة التي تطلبها، إما بلاحقة في العنوان أو بترويسة Accept (content negotiation).

السجل المدمج في ملف الاستناد يحوّل بـ301 إلى السجل الذي دُمج فيه. والعنوان الذي لا يقابله سجل منشور يعيد 404.

البحث

بحث في الفهرس المنشور يفهم العربية: يساوي بين أ وإ وآ وا، وبين ة وه، وبين ى وي، ويتجاهل التشكيل. يجب أن تظهر كل كلمات البحث في السجل، بأي ترتيب.

GET https://mooon.site/resource/search?q=بغداد&limit=20&offset=0
المعاملالمعنى
qكلمات البحث (حتى 200 حرف)
languageرمز اللغة، مثل ara
limit · offsetحجم الصفحة (حتى 200، والافتراضي 50) وموضع البدء
{ "total": 3,
  "facets": { "language": { "ara": 2, "eng": 1 }, … },
  "records": [ { "id": "record-…", "title": "…", "saved": "…", "document": { "@graph": [ … ] } } ] }

يحمل كل سجل في document رسمه البياني BIBFRAME كاملاً بصيغة JSON-LD.

ملف الاستناد

ملف مون الاستنادي يضم الأشخاص والهيئات والأماكن والموضوعات والمحاور. لكل منها عنوان دائم، مع أشكال الاسم الأخرى، وروابط owl:sameAs إلى مكتبة الكونغرس وVIAF وويكي بيانات.

GET https://mooon.site/resource/authorities?q=الوردي&kind=agent&limit=10
المعاملالمعنى
qالاسم أو جزء منه (يطابق الأشكال الأخرى أيضاً)
kindagent · place · topic · hub

    "variants": ["Wardi, Ali al-"], "sameAs": ["https://viaf.org/viaf/…"],
    "uri": "https://mooon.site/resource/agent/ali-al-wardi-3f9a1c2e" } ] }

SPARQL

نقطة SPARQL 1.1 للقراءة فقط، تعمل على كل السجلات المنشورة. فيها SELECT وASK وCONSTRUCT وDESCRIBE، أما أوامر التعديل فمرفوضة. وفي المتصفح صفحة لتجربة الاستعلامات: mooon.site/resource/sparql.

curl -G https://mooon.site/resource/sparql \
  --data-urlencode 'query=PREFIX bf: <http://id.loc.gov/ontologies/bibframe/>
SELECT ?work ?title WHERE { ?work a bf:Work ; bf:title/bf:mainTitle ?title } LIMIT 25'

curl -X POST https://mooon.site/resource/sparql \
  -H "Content-Type: application/sparql-query" -H "Accept: text/csv" \
  --data 'ASK { ?s ?p ?o }'
نوع الاستعلامالصيغ (Accept أو &format=)
SELECT · ASKSPARQL JSON (الافتراضي) · XML · CSV · TSV — json xml csv tsv
CONSTRUCT · DESCRIBETurtle (الافتراضي) · N-Triples · RDF/XML — ttl nt rdfxml

التنزيل الكامل

كل السجلات المنشورة في ملف واحد، محدَّث دائماً ومخزَّن لساعة. العقد الفارغة (blank nodes) لكل سجل تحمل أسماء خاصة به، فلا تختلط بين السجلات.

https://mooon.site/resource/dump.jsonld
https://mooon.site/resource/dump.nt

ويمكن تنزيل كل سجل بصيغ MARC 21 (ISO 2709) وMARCXML و.mrk من صفحته في الفهرس.

سجل التغييرات (Change feed)

ما نشره مون أو عدّله أو سحبه، الأحدث أولاً، بصيغة ActivityStreams 2.0 كما تنشر مكتبة الكونغرس وOCLC سجلَّيهما. كل نشاط Create أو Update أو Delete يسمّي الـ Instance والعمل وروابط تنزيله. تتبَّعه لتحديث نسختك دون تنزيل كل شيء من جديد؛ الصفحة 1 هي الأحدث، 50 نشاطاً في الصفحة.

https://mooon.site/resource/changes
https://mooon.site/resource/changes?page=1

محركات البحث

صفحة كل كتاب في الفهرس تحمل وصفاً بصيغة schema.org/Book بلغة JSON-LD، ورابطاً قانونياً (canonical). وخريطة الموقع تسرد كل الكتب المنشورة:

https://mooon.site/sitemap.xml
https://mooon.site/robots.txt

قوالب الفهرسة (Profiles)

قوالب مون (كتاب، مخطوط، دورية، موسيقى مدونة، خريطة) تحدد حقول كل تسجيلة وأيها إلزامي. تُنشر بثلاث صيغ: صيغة Marva من مكتبة الكونغرس (JSON)، وأشكال SHACL التي تطبقها بوابة النشر، وجدول DCTAP الذي يفتحه محرر القوالب Dancer من مكتبة الكونغرس ويعدّله.

https://gfbagczwhvxxstbfrfhu.supabase.co/functions/v1/make-server-49c0e13c/profiles/monograph
https://gfbagczwhvxxstbfrfhu.supabase.co/functions/v1/make-server-49c0e13c/profiles/monograph/shapes.ttl
https://gfbagczwhvxxstbfrfhu.supabase.co/functions/v1/make-server-49c0e13c/profiles/monograph/dctap.csv

ولتحويل جدول DCTAP معدَّل في Dancer (أو جدول قوالب Marva من مكتبة الكونغرس) إلى صيغة Marva، أرسله في جسم الطلب:

curl -X POST "…/make-server-49c0e13c/profiles/dctap/convert?id=moon:MyProfile&title=My%20profile" \
  -H "Content-Type: text/csv" --data-binary @my-profile.dctap.csv

القوالب المتاحة: monograph · manuscript · serial · music · map.

ملاحظات

  • كل العناوين أعلاه تقبل الطلبات من أي موقع (CORS مفتوح)، ولا تحتاج إلى مفتاح.
  • تظهر في الواجهة النسخة المنشورة من كل سجل وحدها. التعديلات التي تنتظر المراجعة لا تظهر حتى يعتمدها المراجع.
  • يتبع وصف السجلات أنطولوجيا BIBFRAME من مكتبة الكونغرس، ويسير على أعرافها: النص العربي يوسم @ar-Arab وكتابته اللاتينية @ar-Latn، وفئات المحتوى مثل bf:Text.
  • رجاءً لا تُكثر الطلبات المتلاحقة. للحصول على الفهرس كله استعمل التنزيل الكامل بدل البحث صفحةً صفحة.
